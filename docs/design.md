# RefIt design direction

Based on the user's wireframe and gallery-header reference. Design guidance: [unslop](https://github.com/heydamir/unslop) by Damir Sokolovsky, CC BY 4.0.

- Product: a personal image library for artists gathering references.
- Character: calm, tactile, collected.
- World: a studio pinboard and a gallery's printed catalogue.
- Moments: the reference images carry the color, displayed at their own proportions.
- Signature: fine catalogue rules and a serif wordmark, with a quiet image count beside each collection.

The workspace was empty, so there was no existing interface to audit. The supplied references already establish the direction: centered title, utility controls on the sides, generous white space, and an irregular image grid. Preserve that direction rather than introduce a marketing landing page.

Passes: consistent spacing; near-neutral light/dark surfaces; consistent line icons; short functional labels; serif titles with system sans-serif controls; responsive masonry; accessible focus and form states; local example studies rather than unlicensed artwork; motion limited to hover feedback, respecting reduced motion.

Color picking and palette extraction are explicitly deferred at the user's request.
